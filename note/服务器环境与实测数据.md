## 2. 网络（重要）

容器内**没有默认代理**，`/etc/network_turbo` 需手动 source。

| 场景 | 规则 |
|---|---|
| ModelScope 下模型 | **必须直连**（走代理 0.5 MB/s，直连 9.6 MB/s） |
| 阿里云 pip 镜像 | **必须绕开代理**，否则大索引页被截断，会误报 "No matching distribution" |
| pypi.org / GitHub / HuggingFace | 必须走代理（直连全不通） |

标准写法：

```bash
source /etc/network_turbo
export no_proxy="$no_proxy,mirrors.aliyun.com,pypi.tuna.tsinghua.edu.cn"
```

下模型时反过来：

```bash
unset http_proxy https_proxy; export no_proxy='*'
```

## 5. 启动 vLLM

```bash
V=/root/autodl-tmp/venvs/vllm/bin
export PATH="$V:$PATH"
export VLLM_USE_FLASHINFER_SAMPLER=0   # 避免 JIT 编译

$V/python -m vllm.entrypoints.openai.api_server \
  --model /root/autodl-tmp/models/Qwen2.5-7B-Instruct \
  --served-model-name qwen2.5-7b \
  --max-model-len 32768 \
  --gpu-memory-utilization 0.92 \
  --port 8000 --host 127.0.0.1
```

注意：vLLM 0.32 已移除 `--disable-log-requests`，改用 `--no-enable-log-requests`。

## 6. 实测数据（max-model-len=32768）

| 指标 | 值 |
|---|---|
| 启动到就绪 | 80 s |
| 加载后显存 | 21.6 GB / 24.6 GB |
| KV cache | 5.64 GiB = **105,504 tokens** |
| 32K 请求并发 | **3.22x** |
| 单请求解码 | 60.5 tok/s |
| 8K prefill | 9,088 tok/s |

### 显存→并发的换算（关键约束）

| max-model-len | 并发上限 |
|---|---|
| 8K | ~12.9x |
| 16K | ~6.4x |
| 32K | ~3.2x |

研究规划里"3–10 个并发 Agent"在 32K 下达不到，8K–16K 可行。需要更多并发时要降 max-model-len 或上量化。
